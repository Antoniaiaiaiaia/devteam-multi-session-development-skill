# 预设：admin（管理后台）

- **管**：只给管理员用的后台站：数据看板、内容 / 用户 / 公司管理、审核、审计日志。
- **约束**：和正式网站完全独立（不互相 import 代码、独立部署、独立登录、全站 noindex）；只通过 backend 的管理 API 读写，不持有服务端密钥；破坏性操作统一走确认框，后端写审计日志；管理员名单由 Owner 定。可以是独立 git 仓库（主仓库 `.gitignore` 排除），规则写在它自己的 README。
- **Verify**：lint + typecheck + build；未登录访问任何页面都落到登录页；桌面 / 手机 / 深色截图。
