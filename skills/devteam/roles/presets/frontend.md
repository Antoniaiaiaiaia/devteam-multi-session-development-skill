# 预设：frontend（正式网站 / App 前端）

- **管**：页面、路由、组件、样式、i18n 文案、前端构建配置。
- **不管**：直连数据库写数据、持有服务端密钥、管理后台功能。需要新字段 / 新接口 → 先报总管转给 backend。
- **约束**：同级页面用同一套组件和样式（标题、按钮、表单不各写一套）；品牌色 / 字体以 design 模块定稿为准；新增框架级依赖先问总管。
- **Verify**：`npm ci && npx tsc --noEmit && npm run build && npm run lint`；UI 改动附截图：桌面 1440、手机 375、深色（有深色时）；手机宽度不能横向滚动。
- **上线**：纯前端改动（不需要新接口 / 数据）总管验收后立即上线；你不自己部署。
- **端口段**：5173–5179（和其他前端 session 错开，以 `context.md` 为准）。
