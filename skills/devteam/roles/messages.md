# 消息模板

session 之间用 `SendMessage` 传话。第一行要能单独看懂（对方窗口只预览第一行）。

## 上线（模块 → 总管）
```
[<模块>] 上线：/devteam <模块>，session <名字>。负责 <一句话>，端口 <段>。等派活。
```

## 派活（总管 → 模块）
```
新任务（<模块>）：<一句话目标>。分支 <模块>/<topic>。
Owner 原话："<原话，逐字>"
要求：
- <具体要做的，一条一行>
验收：<Verify 命令 / 截图尺寸 / 线上要看到什么>
先回报再做：<推 migration / 部署 / 对外发 / 删数据 …，没有就写"无">
做完：回报 分支 + hash + Verify 结果。
```

## 回报（模块 → 总管）
```
[<模块>] <分支> 做完待验收：hash <hash>（基于 main <hash>）。
做了什么：<一两句>
Verify：<命令> → <结果>（我自己跑过）
截图：<路径>（UI 改动才有）
要 Owner 的：<无 / 选项，推荐的放第一个并写理由>
注意：<没做完的、已知局限、风险>
```

## 退回（总管 → 模块）
```
<分支> <hash> 还不能合：
1. <文件:行号> — <问题> → <改成什么>
同分支继续提交，改完回报新 hash。
```

## 合并通知（总管 → 模块）
```
<分支> <hash> 已合并为 <hash>，<已上线 / 未上线，原因>。线上核对：<结果>。请清理 worktree 和分支。
```

## 更正 / 暂停（总管 → 模块）
```
更正（Owner 刚说）："<原话>"。<之前哪条要求作废>，改成：<新要求>。
```
```
暂停：Owner 要求"<原话>"。立刻停（包括后台脚本），回我一句停在哪、已做了什么。
```

## 问 Owner（总管 → Owner，用 AskUserQuestion）
每个问题：背景一句；选项 2–4 个，推荐项放第一个、标 (Recommended)、写理由；影响什么、谁在等。一次最多 4 个问题，能合并的合并。
